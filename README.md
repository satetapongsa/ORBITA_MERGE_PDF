## 🌟 Overview (ภาพรวมระบบ)

**ORBITA Studio** is an ultra-fast, privacy-first multimedia and document processing powerhouse. It unifies professional PDF operations with cutting-edge social media video downloads, FFmpeg video/audio transcoding, rich in-browser Microsoft Word editing, and batch image conversions under a sleek cosmic glassmorphic UI.

- 🚀 **Zero Data Leakage:** High-security document and media processing without cloud lock-in.
- 🎬 **Social Video Engine:** Direct extraction from TikTok, YouTube (up to 4K), Instagram Reels, and Facebook with live 0-100% progress.
- 🎵 **Studio Audio Transcoder:** Extract crystal-clear 320 kbps MP3 audio from any video.
- 📝 **Live Word Studio:** Type, format, and instantly export real `.docx` files or import existing documents.
- 🎨 **Cosmic UI/UX:** Dark/Light theme, English & Thai bilingual support, keyboard shortcuts (`/`), and drag-and-drop workspace.

## 🚀 Getting Started (วิธีเริ่มใช้งาน)

### Prerequisites
- Node.js 18+
- Python 3.10+ (with `flask`, `yt-dlp`, `python-docx`, `pypdf`, `pillow`)
- FFmpeg installed

### 1-Click Launch (Windows)
Double-click `run.bat` or execute in PowerShell:
```powershell
.\run.ps1
```
> **No Y/N prompt on exit:** Press `Ctrl + C` anytime to immediately shut down cleanly.

### Manual Launch
```bash
# Terminal 1: Python Engine
python python_engine/server.py

# Terminal 2: Vite Frontend
npm install
npm run dev
```

- Frontend URL: **http://localhost:3003/**
- Backend API Engine: **http://localhost:5001/**
